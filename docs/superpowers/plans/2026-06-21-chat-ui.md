# Chat UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one shared, reusable chat component layer that powers a new user-facing chat route in `apps/web` and the existing admin debug chat in `apps/admin`, differing only by a density-driven config.

**Architecture:** Three layers mirroring `docs/sidebar-design.md`: (1) shadcn/ai-elements primitives in `packages/ui` (extended), (2) a shared assembler (`ChatThread`, `ChatComposer`, `ChatShell`, `ChatProvider`) driven by a `ChatConfig` context, (3) per-app wiring. The single diverging input is `ChatConfig` (comfortable for web, compact for admin). Rendering components are presentational and consume a shared `ChatMessage[]`; data hooks stay per-app.

**Tech Stack:** React 19, TanStack Start/Router, Tailwind v4, shadcn (`base-lyra`/neutral), base-ui primitives, Geist + Geist Mono, lucide-react, oRPC + TanStack Query, vitest (logic only).

Full design rationale: `docs/chat-design.md`.

## Global Constraints

- **Theme:** monochrome OKLCH neutral. `destructive` is the only non-neutral, errors only. No new palette, no AI-purple.
- **Fonts:** Geist sans = human voice; Geist Mono = machine voice (tokens, latency, raw args, tool names).
- **Shape:** one radius scale, `--radius: 0.625rem`. Use `rounded-lg` for bubbles/blocks/composer.
- **Theme lock:** one theme per page; light/dark via existing tokens only. No section inversion.
- **No em-dashes (`—`/`–`) anywhere** in code, copy, comments, or UI strings. Use `-`.
- **Icons:** lucide-react only (project standard), `size-3.5`/`size-4` consistent.
- **Primitives:** base-ui (`@base-ui/react/*`), not Radix.
- **Imports:** shared components via `@better-agent/ui/components/<name>`, libs via `@better-agent/ui/lib/<name>`.
- **Motion:** restrained; honor `prefers-reduced-motion`. No parallax/marquee/scroll-hijack.
- **Lint/format:** `pnpm check` (ultracite/biome) must pass; run `pnpm fix` to auto-fix.
- **Package manager:** pnpm. Filter syntax: `pnpm --filter @better-agent/ui`, `pnpm --filter admin`, `pnpm --filter web`.

## Testing strategy

`packages/ui` and the apps have no component-test runner; only logic packages use vitest. So:
- **Pure logic** (`chat-config.ts`) gets real vitest TDD (Task 2 adds vitest to `packages/ui`).
- **Visual components** are verified by typecheck + biome + running the app and observing. Per-task verification commands are given; phase-boundary tasks run the dev server.

Verification commands used throughout:
- UI types: `pnpm --filter @better-agent/ui check-types`
- Admin types: `pnpm --filter admin check-types`
- Web types: `pnpm --filter web exec tsc --noEmit`
- Lint/format: `pnpm check`
- UI unit tests: `pnpm --filter @better-agent/ui test`

```ts
export type ChatDensity = "comfortable" | "compact";
export type ChatReasoningMode = "hidden" | "collapsed" | "expanded";
export type ChatToolDetail = "summary" | "raw";
export type ChatMessageAction = "copy" | "retry" | "edit" | "raw";

export type ChatConfig = {
	density: ChatDensity;
	showReasoning: ChatReasoningMode;
	showMeta: boolean;
	showToolDetail: ChatToolDetail;
	messageActions: ChatMessageAction[];
};

export type DensityTokens = {
	thread: string;
	turnGap: string;
	assistantProse: string;
	messagePadding: string;
	metaText: string;
};

const COMFORTABLE_TOKENS: DensityTokens = {
	thread: "mx-auto w-full max-w-3xl",
	turnGap: "gap-6",
	assistantProse: "text-[15px] leading-7",
	messagePadding: "px-4 py-3",
	metaText: "hidden",
};

const COMPACT_TOKENS: DensityTokens = {
	thread: "w-full max-w-none",
	turnGap: "gap-3",
	assistantProse: "text-sm leading-6",
	messagePadding: "px-3 py-2",
	metaText: "font-mono text-muted-foreground text-xs",
};

export function resolveDensityTokens(density: ChatDensity): DensityTokens {
	return density === "comfortable" ? COMFORTABLE_TOKENS : COMPACT_TOKENS;
}

export const COMFORTABLE_CONFIG: ChatConfig = {
	density: "comfortable",
	showReasoning: "collapsed",
	showMeta: false,
	showToolDetail: "summary",
	messageActions: ["copy", "retry", "edit"],
};

export const COMPACT_CONFIG: ChatConfig = {
	density: "compact",
	showReasoning: "expanded",
	showMeta: true,
	showToolDetail: "raw",
	messageActions: ["copy", "retry", "raw"],
};
```

- [ ] **Step 1: Create the component**

Create `packages/ui/src/components/message-meta.tsx`:

```tsx
import type { ChatMessageMeta } from "@better-agent/ui/lib/chat-message";
import { cn } from "@better-agent/ui/lib/utils";

const MS_PER_SECOND = 1000;

export function MessageMeta({
	meta,
	className,
}: {
	meta: ChatMessageMeta;
	className?: string;
}) {
	const items: string[] = [];
	if (meta.model) {
		items.push(meta.model);
	}
	if (meta.tokensIn !== undefined || meta.tokensOut !== undefined) {
		items.push(`${meta.tokensIn ?? 0}/${meta.tokensOut ?? 0} tok`);
	}
	if (meta.latencyMs !== undefined) {
		items.push(`${(meta.latencyMs / MS_PER_SECOND).toFixed(1)}s`);
	}
	if (meta.finishReason) {
		items.push(meta.finishReason);
	}
	if (items.length === 0) {
		return null;
	}
	return (
		<div
			className={cn(
				"flex flex-wrap gap-x-3 gap-y-0.5 font-mono text-muted-foreground text-xs",
				className
			)}
		>
			{items.map((item) => (
				<span key={item}>{item}</span>
			))}
		</div>
	);
}
```

```tsx
	name,

	args,
	result,
	status = "ok",
	detail = "raw",
	defaultOpen = false,
```

```tsx
function AssistantBody({ message }: { message: ChatMessage }) {
	const config = useChatConfig();
	const tokens = resolveDensityTokens(config.density);
	const streamingEmpty = message.status === "streaming" && message.text === "";
	const showCopy =
		config.messageActions.includes("copy") &&
		message.status === "complete" &&
		message.text !== "";
	return (
		<div className="flex flex-col gap-2">
			{config.showReasoning !== "hidden" && message.reasoning !== "" ? (
				<Reasoning
					defaultOpen={config.showReasoning === "expanded"}
					isStreaming={message.status === "streaming"}
				>
					<ReasoningTrigger label="Reasoning" />
					<ReasoningContent>{message.reasoning}</ReasoningContent>
				</Reasoning>
			) : null}
			{streamingEmpty ? (
				<Loader />
			) : (
				<Response className={tokens.assistantProse}>{message.text}</Response>
			)}
			{message.status === "error" ? (
				<Badge variant="destructive">Error</Badge>
			) : null}
			{config.showMeta && message.meta ? (
				<MessageMeta meta={message.meta} />
			) : null}
			{showCopy ? <CopyAction text={message.text} /> : null}
		</div>
	);
}

function ChatRow({ message }: { message: ChatMessage }) {
	const config = useChatConfig();
	const showAvatar = config.density === "compact";
	if (message.role === "user") {
		return (
			<Message from="user" showAvatar={showAvatar}>
				<MessageContent from="user">
					<p className="whitespace-pre-wrap text-sm">{message.text}</p>

			</Message>
		);

	return (
		<Message from="assistant" showAvatar={showAvatar}>
			<MessageContent className="bg-transparent px-0 py-0" from="assistant">
				<AssistantBody message={message} />
			</MessageContent>
		</Message>
	);
}

	empty,
```

```ts
import type { ChatMessage } from "@better-agent/ui/lib/chat-message";
import type { QueryClient } from "@tanstack/react-query";
import { useQuery, useQueryClient } from "@tanstack/react-query";
import { useEffect, useRef, useState } from "react";

import type { SessionMessageRow } from "@/utils/api-types";
import { client, orpc } from "@/utils/orpc";

function partStatus(
	status: SessionMessageRow["message"]["status"]
): ChatMessage["status"] {
	if (status === "complete") {
		return "complete";
	}
	if (status === "error") {
		return "error";
	}
	if (status === "aborted") {
		return "complete";
	}
	return "streaming";
}

function toChatMessage(entry: SessionMessageRow): ChatMessage {
	let text = "";
	let reasoning = "";
	for (const part of entry.parts) {
		if (part.type === "text") {
			text += part.content.text;
		} else if (part.type === "reasoning") {
			reasoning += part.content.text;
		}
	}
	return {
		id: entry.message.id,
		role: entry.message.role,
		text,
		reasoning,
		status: partStatus(entry.message.status),
	};
}

interface StreamArgs {
	assistant: ChatMessage;
	sessionId: string;
	setDraft: (msgs: ChatMessage[]) => void;
	signal: AbortSignal;
	text: string;
	user: ChatMessage;
}

async function streamPrompt(args: StreamArgs) {
	const { sessionId, text, signal, user, assistant, setDraft } = args;
	const iterator = await client.sessions.prompt({ sessionId, text }, { signal });
	for await (const event of iterator) {
		if (event.type === "text-delta") {
			assistant.text += event.delta;
		} else if (event.type === "reasoning-delta") {
			assistant.reasoning += event.delta;
		} else if (event.type === "error") {
			assistant.status = "error";
		}
		setDraft([user, { ...assistant }]);
	}
}

interface SendArgs {
	abortRef: React.MutableRefObject<AbortController | null>;
	queryClient: QueryClient;
	sessionId: string;
	setDraft: (msgs: ChatMessage[]) => void;
	setStreaming: (v: boolean) => void;
	streaming: boolean;
}

async function finalizeSend(sessionId: string, args: SendArgs) {
	args.setStreaming(false);
	args.abortRef.current = null;
	await args.queryClient.invalidateQueries({
		queryKey: orpc.sessions.listMessages.key({ input: { sessionId } }),
	});
	args.setDraft([]);
}

async function sendMessage(text: string, args: SendArgs) {
	if (args.sessionId === "" || args.streaming) {
		return;
	}
	const controller = new AbortController();
	args.abortRef.current = controller;
	args.setStreaming(true);
	const user: ChatMessage = {
		id: "draft-user",
		role: "user",
		text,
		reasoning: "",
		status: "complete",
	};
	const assistant: ChatMessage = {
		id: "draft-assistant",
		role: "assistant",
		text: "",
		reasoning: "",
		status: "streaming",
	};
	args.setDraft([user, assistant]);
	try {
		await streamPrompt({
			sessionId: args.sessionId,
			text,
			signal: controller.signal,
			user,
			assistant,
			setDraft: args.setDraft,
		});
	} catch {
		if (!controller.signal.aborted) {
			assistant.status = "error";
			args.setDraft([user, { ...assistant }]);
		}
	} finally {
		await finalizeSend(args.sessionId, args);
	}
}

export function useChat(sessionId: string) {
	const queryClient = useQueryClient();
	const history = useQuery(
		orpc.sessions.listMessages.queryOptions({
			input: { sessionId },
			enabled: sessionId !== "",
		})
	);
	const [draft, setDraft] = useState<ChatMessage[]>([]);
	const [streaming, setStreaming] = useState(false);
	const abortRef = useRef<AbortController | null>(null);

	useEffect(() => () => abortRef.current?.abort(), []);

	const messages: ChatMessage[] = [
		...(history.data ?? []).map(toChatMessage),
		...draft,
	];

	const send = (text: string) =>
		sendMessage(text, {
			sessionId,
			streaming,
			abortRef,
			setStreaming,
			setDraft,
			queryClient,
		});

	const stop = () => {
		abortRef.current?.abort();
	};

	return { messages, streaming, send, stop };
}
```

```ts
import { useMutation, useQuery } from "@tanstack/react-query";
import { useEffect, useState } from "react";

import { orpc } from "@/utils/orpc";

export function useDefaultSession() {
	const agents = useQuery(orpc.agents.list.queryOptions());
	const [sessionId, setSessionId] = useState("");
	const create = useMutation(
		orpc.sessions.create.mutationOptions({
			onSuccess: (session) => setSessionId(session.id),
		})
	);

	const firstAgentId = agents.data?.[0]?.id;
	const shouldCreate =
		sessionId === "" &&
		firstAgentId !== undefined &&
		!(create.isPending || create.isSuccess);

	useEffect(() => {
		if (shouldCreate && firstAgentId) {
			create.mutate({ agentId: firstAgentId });
		}
	}, [shouldCreate, firstAgentId, create]);

	const noAgents = agents.isSuccess && (agents.data?.length ?? 0) === 0;

	return {
		sessionId,
		ready: sessionId !== "",
		loading: agents.isLoading || create.isPending,
		noAgents,
	};
}
```

**Interfaces:**

- Produces: `SessionInspector({ sessionId, selectedMessageId })`.

The inspector shows the raw `SessionMessageRow` JSON for the selected message (and the full list when none is selected). This is concrete with existing data; richer structured meta/tool rendering is a follow-up gated on the backend exposing model/token/tool-part data.

- [ ] **Step 1: Create the inspector**

Create `apps/admin/src/components/sessions/inspector.tsx`:

```tsx
import { useQuery } from "@tanstack/react-query";

import { orpc } from "@/utils/orpc";

export function SessionInspector({
	sessionId,
	selectedMessageId,
}: {
	sessionId: string;
	selectedMessageId: string | null;
}) {
	const history = useQuery(
		orpc.sessions.listMessages.queryOptions({
			input: { sessionId },
			enabled: sessionId !== "",
		})
	);
	const rows = history.data ?? [];
	const selected = selectedMessageId
		? rows.find((row) => row.message.id === selectedMessageId)
		: null;
	const payload = selected ?? rows;
	return (
		<div className="flex h-full flex-col overflow-hidden">
			<div className="border-b px-3 py-2 font-medium text-sm">
				{selected ? "Message" : "Session"}
			</div>
			<pre className="flex-1 overflow-auto p-3 font-mono text-muted-foreground text-xs">
				{JSON.stringify(payload, null, 2)}
			</pre>
		</div>
	);
}
```
